# Space War (Web Edition)

An alien defense arcade shooter game built with Python and Pygame-CE. Defend the planet from waves of dropping alien bombs.

Playable locally and in modern web browsers via WebAssembly ([Pygbag](https://pygame-web.github.io/)).

## How to Run Locally

### Prerequisites
- Python 3.10+
- `pip install pygame-ce pygbag`

### Play Locally
```bash
python main.py
```

### Run in Browser Locally
```bash
python -m pygbag main.py
```
Open `http://localhost:8000` in your web browser.

## Controls
- **Left / Right Arrow Keys**: Move ship
- **Space**: Fire shot / restart after game over
- **F**: Toggle fullscreen
- **Escape**: Quit game
